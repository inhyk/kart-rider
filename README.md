## v0.3.1 · 자동 코스 진행과 조향 안정화

1·2라운드 완주 후 6초 뒤 다음 코스로 자동 이동합니다. 자동 이동을 멈추거나 상세 기록을 열면 결과를 계속 볼 수 있고, 출발 버튼으로 바로 이동할 수도 있습니다. 최종 결과는 자동으로 닫히지 않습니다. 조향 도움은 입력과 접지력을 안정시키며 도로 방향으로 카트를 자동으로 되돌리지 않습니다.

# 3라운드 토너먼트 · v0.3.0

선택한 코스부터 세 코스를 한 번씩 달립니다. 라운드별 1~6위에게 10/7/5/3/2/1점을 주며, 합계 점수로 우승자를 정합니다. 동점은 높은 순위 횟수, 마지막 라운드 순위 순으로 결정합니다. 플레이어가 완주한 순간의 순위를 사용합니다. 일시정지에서 이번 라운드를 다시 시작해도 앞 라운드 점수는 유지됩니다. 로비로 나가거나 새 토너먼트를 시작하면 대회 점수는 초기화됩니다.

# 카트라이더 · 포켓 그랑프리

직접 만든 카트와 코스로 즐기는 3D 카트 레이싱 팬 게임입니다. Babylon.js로 그린 숲, 협곡, 야간 항구를 달리며 AI 카트 다섯 대와 세 바퀴를 겨룹니다. 원작의 이미지, 모델, 음악 파일을 사용하지 않습니다.

- 실제 방향과 관성으로 달리는 카트 3종, 도색 6종
- 서로 다른 경로의 클로버 파크 / 선셋 캐니언 / 네온 하버
- 7종 아이템, 두 칸 보관함, 움직이는 공격과 방어 효과
- 드리프트, 미니 터보, 슈퍼 터보, 니트로, 스타트 대시
- 아이템전과 스피드전, 난이도 3종, 조향 도움
- 모바일 멀티터치 조작, 일시정지, 코스별 최고 기록과 바퀴별 기록
- 직접 합성하는 엔진음, 타이어 소리, 음악과 효과음

## 실행

Node.js 22.12 이상에서 실행합니다. 검증에는 Node.js 24를 사용했습니다.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

허브 저장소 안에서는 `npm run kart-rider:dev`로 개발 서버를 켭니다. 사용자 테스트 서버 5193은 검증된 정적 빌드입니다. 후보 빌드를 5195에서 검증한 후 `npm run kart-rider:promote`로 반영합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| ← → / A D | 조향 (자동 가속) |
| ↓ / S | 브레이크 |
| Shift + 조향 | 드리프트. 게이지를 모은 뒤 놓으면 터보 |
| Space | 니트로. 출발 직전에 누르면 스타트 대시 |
| E / Ctrl | 아이템 사용 |
| Q | 두 아이템의 순서 교체 |
| R | 트랙 중앙으로 복귀 |
| C | 카메라 거리 변경 |
| P / Esc | 일시정지 |

모바일에서는 화면 버튼을 사용합니다. 브라우저 탭을 벗어나거나 그래픽 연결이 끊기면 레이스를 일시정지합니다. 소리 설정과 카트 선택, 최고 기록은 브라우저에 저장됩니다.

드리프트 중에는 Shift를 계속 누른 채 방향을 바로잡을 수 있습니다. 멈추거나 공격을 받으면 충전이 취소됩니다. 모바일의 트랙 복귀는 일시정지 메뉴에 있습니다.

## 파일

`core.mjs`는 화면과 독립적인 시뮬레이션입니다. `tracks.mjs`가 코스 형상과 위치 투영을, `world.js`와 `vehicle.js`가 환경과 카트를, `effects.js`와 `skidmarks.js`가 효과를 담당합니다. 기본 테스트는 실제 조향으로 모든 코스를 완주하고 아이템, 충돌, 기록과 복귀 동작을 검증합니다.
